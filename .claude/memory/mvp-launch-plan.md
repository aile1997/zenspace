## 🚀 MVP 必需功能（优先级 P0）

### 1. 座位预约核心流程 ⭐⭐⭐

**用户旅程**:
```
选择区域 → 选择座位 → 选择时段 → 确认预约 → 完成
```

#### 后端 API（Ticket-006）
- `POST /bookings` - 创建预约
- `GET /bookings/my` - 查询我的预约
- `DELETE /bookings/:id` - 取消预约
- `GET /zones` - 获取区域列表
- `GET /zones/:id/seats` - 获取区域座位

**预计工时**: 6-8 小时

---

#### 前端 UI
- 座位选择页（8x6 网格，显示座位状态）
- 预约确认弹窗
- 我的预约列表

**预计工时**: 4-6 小时

---

### 2. 基础数据初始化

创建初始数据脚本：
```typescript
// backend/prisma/seed.ts
- 创建 3 个区域（1F/2F/3F）
- 每个区域 48 个座位
- 初始状态为"可用"
```

**预计工时**: 1 小时

## 🔧 简化方案（MVP 特殊处理）

### 1. 测试策略简化

**原方案**: 18+ 测试用例，覆盖率 ≥ 80%  
**MVP 方案**: 5-10 个关键路径测试即可

```typescript
// 只测试核心流程
✅ 用户登录成功
✅ 创建预约成功
✅ 查询预约成功
✅ 取消预约成功
❌ 不测试边界情况（MVP 后补充）
```

**节省工时**: 从 6 小时 → 2 小时

---

### 2. 数据验证简化

**原方案**: 完整的 DTO 验证 + 业务规则校验  
**MVP 方案**: 基础验证即可

```typescript
// 基础验证
✅ 必填字段检查
✅ 时间范围合法性
❌ 复杂的业务规则（如信用分检查）延后
```

---

### 3. 错误处理简化

**原方案**: 详细的错误码 + 多语言支持  
**MVP 方案**: 简单的错误消息

```typescript
// MVP 错误处理
throw new BadRequestException('预约失败');
// 而不是复杂的错误码系统
```

---

### 4. 功能裁剪

**暂时移除的功能**（MVP 后添加）:
- ❌ 积分商城
- ❌ 信用分系统
- ❌ 推送通知
- ❌ 分享功能
- ❌ 评价系统

**保留的核心功能**:
- ✅ 用户登录
- ✅ 座位预约
- ✅ 预约管理

## 🚦 不在 MVP 范围内的功能

### 可以延后的功能
1. **完善的测试覆盖** (Ticket-005)
   - 当前：5-10 个核心测试
   - 后续：补充到 80% 覆盖率

2. **积分商城**
   - MVP 不需要积分系统
   - 用户预约即可，无需积分兑换

3. **信用分系统**
   - MVP 阶段不做违约惩罚
   - 后续根据数据优化

4. **推送通知**
   - MVP 阶段只有页面内展示
   - 后续添加微信/短信通知

5. **多语言支持**
   - MVP 只支持简体中文
   - 国际化延后

## 📝 API 文档（简化版）

### 预约相关 API

#### 创建预约
```http
POST /api/bookings
Authorization: Bearer <token>

{
  "seatId": "seat-1",
  "startTime": "2026-01-27T14:00:00Z",
  "endTime": "2026-01-27T16:00:00Z"
}

Response:
{
  "id": "booking-1",
  "seat": { ... },
  "startTime": "...",
  "endTime": "...",
  "status": "CONFIRMED"
}
```

#### 查询我的预约
```http
GET /api/bookings/my
Authorization: Bearer <token>

Response:
{
  "bookings": [
    {
      "id": "booking-1",
      "seat": { ... },
      "startTime": "...",
      "status": "CONFIRMED"
    }
  ]
}
```

#### 取消预约
```http
DELETE /api/bookings/:id
Authorization: Bearer <token>

Response: 204 No Content
```
